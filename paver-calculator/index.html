How many pavers do I need?

The calculation compares the total project area with the face area of one paver. For a rectangular layout, multiply the project length by width, then divide by the area of a single paver. The calculator adds your chosen waste allowance and rounds up to a whole unit.

This is a quantity estimate, not a laying plan. It tells you roughly how many units are needed, while the final layout still depends on joint width, pattern, borders and cuts.

Paver calculation example

A 5 m × 4 m patio covers 20 m². A 20 cm × 10 cm paver covers 0.02 m², so the theoretical count is 1,000 pavers. With 10% waste, the estimate becomes 1,100 pavers.

If the same area used much larger paving slabs, the number of units would fall even though the total surface area stayed the same.

The calculator does not prescribe a waste percentage because project geometry matters. Ten percent is a useful starting point, not a universal rule.

Joint width and effective paver size

Pavers are normally separated by joints rather than installed perfectly edge-to-edge. A joint increases the effective module size and can slightly reduce the number of pavers required across a large area. For small joints and typical landscaping projects, the difference may be modest compared with cutting waste. If precision matters, enter the paver dimensions plus the planned joint spacing as the effective module.

Mixed-size paving systems

Some patio products use several stone sizes in a repeating pattern. In that case, counting one individual paver type may not be the best method. Manufacturers often sell those systems by pack coverage, for example a pack covering a stated number of square metres or square feet. Use the project area plus waste and compare it with the manufacturer's pack coverage.

The calculator is most direct for one repeated paver size, but the area result is still useful when planning mixed packs.

Remember the base and bedding layers

The paver count covers only the paving units. A typical installation can also include excavated depth, compacted aggregate base, bedding sand, edge restraints and jointing material. Those materials follow different formulas and should be calculated separately.

For bedding material, use the Sand Calculator. For an aggregate foundation, use the Gravel Calculator. Keeping the quantities separate helps avoid accidentally treating the full excavation depth as one material.

Measuring an irregular patio or path

Split L-shaped patios into rectangles and add the areas. For a path that changes width, divide it into sections and measure each section separately. Curved edges can be approximated with smaller rectangles or by measuring an average width at several points. The goal is to avoid one oversized rectangle that includes areas that will never be paved.

Edge cuts, borders and spare pavers

Border courses can change the number of standard field pavers because they occupy part of the project area. If the border uses a different product, calculate its linear quantity separately. It can also be sensible to keep a small number of spare pavers after installation. A future replacement is easier when you already have material from the same colour batch and finish.

Paver size versus handling and appearance

Large-format slabs cover more area per piece and create fewer joints, while smaller pavers can adapt more easily to curves and detailed patterns. The calculator is neutral about which is better; it simply uses the dimensions you enter. When comparing products, look at both the unit count and how the chosen size suits the pattern, cutting tools and site access.

Frequently asked questions

How much waste should I allow?

Simple rectangles often need less waste than diagonal layouts, curves or detailed patterns. Ten percent is a common planning allowance, not a rule.

Does mortar or joint width affect the count?

Yes. Joint spacing increases the effective module size. Include it in the entered dimensions if the difference is important.

Can I calculate imperial pavers?

Yes. Switch to Imperial: area dimensions are entered in feet and paver dimensions in inches.

Can I use this for driveway pavers?

Yes for quantity, but the calculator does not design the structural base required for vehicle loads.

Should I count pavers or use pack coverage?

Use individual count for one repeated size. For mixed-size systems sold as complete packs, manufacturer pack coverage is usually easier.

Does the result include sand?

No. Bedding and jointing materials are separate quantities.
